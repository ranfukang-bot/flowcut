# FlowCut 全自动 AI 视频工作台

当前桌面版本：`1.4.9`（个人本机版）

## GitHub 源码说明

这是源码仓库，GitHub 的 **Download ZIP** 下载的是源码，不是可双击运行的桌面程序。当前尚未在本仓库发布 EXE 安装包。

仓库不包含账号登录状态、Cookie、个人密钥、商品库、任务数据库、真实成片或运行日志；测试目录中的样例文件仅用于自动化测试。不要把 `%APPDATA%/FlowCut全自动AI视频工作台`、插件生成的 `bridge-config.json` 或账号配置提交到 Git。

在 Windows 开发环境准备源码依赖：

```powershell
npm ci
npm ci --prefix gemini-web-workbench
npm install --prefix vendor/publisher
```

运行桌面开发版：`npm start --prefix gemini-web-workbench`。构建 Windows 程序包：`npm run build:win --prefix gemini-web-workbench`。GitHub 仓库保留原有 MPL-2.0 LICENSE；第三方依赖仍遵循各自许可证。

- TikTok 登录的主页面、子框架、重定向和登录子窗口统一拦截 bytedance 等外部应用协议，避免弹出 Windows 应用选择或商店提示。

## 1.4.4 广告户模型与登录（2026-09-19）

- 广告户默认使用 Seedance 2.0 Fast（2000012），可逐个账号设为普通 2.0（2000004）；接口禁止 Mini。
- 平台明确返回 Fast 额度不足时，保存该账号的等待状态，在所有页面显示选择提醒。确认后仅当天改用普通 2.0，也可选择等待 Fast；跨本地日期重新尝试，以平台实际返回为准。
- 并发和请求频率限制继续等待，不误判为每日额度耗尽；模型偏好和额度选择重启后保留。
- TikTok 登录会话使用当前 Chromium 的浏览器标识和系统代理；增加“重连登录”及不含 Cookie/请求参数的网络错误提示。保留账号资料，登录验证仍由用户完成。

## 1.4.3 自选归档文件夹（2026-09-19）

- 创作中心可为每个归档名称选择或更换实际保存文件夹，视频直接保存到该文件夹。
- 创建任务时固定所选 Gem 指令、商品 ID 和归档位置，后续修改设置不影响已创建任务。
- 自动完成提示词、视频生成和下载；有商品 ID 使用 ID 命名，没有则保留下载响应提供的原视频文件名。同名文件添加序号，避免覆盖。
- 继续处理视频渲染等待；没有收到有效完整视频前不会标记下载成功。

`1.3.12` 新增独立“爆款复刻”模块：上传对标视频与产品图后，Gemini 网页 Pro 会在同一对话内先拆解结构、再换产品改编，随后自动进入 Seedance，并沿用 TK 账号文件夹与商品 ID 成片命名规则。该模块使用锁定的内部指令，不会出现在普通 Gem 模板列表中。

FlowCut 是本机运行的 Electron 工作台，把商品图片、用户自建 Gem、Gemini
网页版/API、内置 Seedance 执行器、并发任务队列和按 TK 账号归档下载整合在一个
程序中。

- 主窗口重新激活时恢复页面键盘焦点。Gem 新建/编辑自动聚焦、保留输入草稿，保存失败明确提示并允许重试。
- 隔离资料验证确认/取消后输入、新建、修改、保存失败保留内容及重试成功，不改用户模板。

## 1.4.1 日常使用优化（2026-09-17）

- 任务队列新增“清除全部任务”：暂停执行器，清除完整制作队列与关联排期（包括未显示的旧任务），取消本机后续执行，防止迟到回调恢复已清任务；商品、模板、成片文件保留。已经提交到远端的生成无法撤销。
- 商品库按本机添加日期分组，提供日期筛选与商品名称/ID 搜索，保留原始添加日期。
- 下载优先使用商品 ID 命名；同名并发下载原子落盘并加序号，不覆盖原片。
- 渲染等待响应、HTML/JSON 错误页、残缺 MP4 不会成为成片；后台定时刷新结果并重试下载，无需重新生成。
- 传输使用完整 ZIP 程序包。个人资料位于 AppData，不包含在程序包；跨电脑搬迁见包内说明，需要重新登录平台并核对本机路径。

## 1.4.0 个人本机版（2026-09-17）

- 移除云端授权登录、到期限制、任务执行许可和商业版自动更新；无需连接原来的授权服务器即可进入工作台。
- 首次升级保留账号、模板、商品与任务，暂停 Gemini 和 Seedance 队列；检查旧任务后再手动继续。
- 商品库可打开新版 FastMoss 插件目录，或导入选品 JSON。商品 ID 按文本保存、重复导入去重，缺图可在商品编辑中补充。
- 手机扫码添加橱窗仍由使用者完成。成片详情中确认内容与橱窗后，可将视频按商品 ID 命名送入同名账号的发布目录。
- 新增“发布管理”，复用原工作台的浏览器环境、账号、发布时间节点与精确商品 ID 挂车功能。首次迁移发布配置，发布队列保持停止，需要手动启动。
- 个人版不再调用历史云端授权/更新接口；历史服务源码留存以便回溯，不作为个人版运行依赖。
- Gemini、TikTok 的网页登录、网络、平台配额仍需正常可用。

## 1.3.18 本机优化（2026-09-17）

- 日常导航集中为创作、任务、商品、模板、账号与设置；剧本、复刻和日历保留在“更多工具”。移除无效额度展示，任务支持按状态、商品 ID 和账号筛选。
- Gemini 只在新回复停止生成并稳定后取走结果；持续输出允许超过 90 秒；无输出、停滞、页面崩溃与失去响应分别处理，并沿用有限次数的后台恢复。
- 任务列表显示具体 Gemini 账号、处理阶段和已接收字数。
- 桌面发布仅携带 Wrangler 运行依赖，不再包含完整前端开发工具链；应用约 1,047 MiB → 512 MiB。
- 本机服务启动取消不需要的 Cloudflare 地理信息请求。
- 构建运行依赖：`npm --prefix gemini-web-workbench run build:runtime`。正式构建 `build:win` 已自动包含此步骤。

## 剧本提示词流水线

左侧“剧本提示词”可直接粘贴任意一集新剧本，并选择本机已登录的 Gemini 网页 Pro
账号。工作台会依次完成格式化改写、角色与场景提取、完整分镜拆解、按原顺序组合
分镜，以及 Seedance 2.5 提示词优化。每组未优化分镜合计不超过 25 秒；合计超过
20 秒时最终提示词压缩为一个连续 20 秒视频，20 秒以内则保留原时长。页面会保留
所有中间结果，并为每条最终提示词提供独立复制按钮。生图和生视频暂不在该模块执行。

## 数据边界

- Gem、商品库、商品图片、Gemini/TikTok 登录态、任务和成片保存在每台电脑本机。
- 个人版不连接原来的 FlowCut 云端授权与更新服务。
- 发给别人的安装包不包含制作方电脑的本地 AppData 或网页登录状态。
- Gemini 和 Seedance 生成任务会按功能需要把任务图片和提示词发送到相应第三方平台。

要求 Node.js `>=22.13.0`。

```bash
npm install
npm --prefix vendor/publisher install
npm test
npm run lint
cd gemini-web-workbench
npm install
npm run check
npm test
npm run build:win
```

以下为历史商业版说明，个人版已停用这些机制。

从 `1.3.0` 起，正式安装版会通过自有 Cloudflare 控制中心自动检查和下载更新。
安装包、差分 blockmap 和 `latest.yml` 元数据分块保存在 Cloudflare Workers KV，
Workers 更新路由负责版本查询、HTTP Range 下载和断点续传。发布新版本时先构建安装包，再在项目根目录执行
`npm run desktop:update:publish`。免安装版不作为自动更新交付渠道。

授权套餐的并发数按“每台设备”计算，而不是一个账号下所有设备合计。基础版为
1 台设备 × 每台 3 条，专业版为 2 台 × 每台 8 条，团队版为 5 台 × 每台
20 条；旗舰版为 10 台且每台不限并发。定制版的设备数和每台并发数由管理员
在账号编辑窗口单独填写。

桌面程序源码位于 `gemini-web-workbench/`，内置 Seedance 引擎位于
`vendor/seedance-engine/`。项目已经自包含，不再依赖另一份 Seedance 工作台源码。
