当前桌面版本：`1.4.23`（个人本机版）

## 1.4.23 Gemini 对话输入与发送（2026-10-02）

参考网页插件，图片优先粘贴真实字节、原生文件选择器备用；文字优先经页面编辑器写入，按归一化空白后的完整原文校验，取消 90% 字数放行。优先点击发送按钮，仅原输入未变化且没有发送迹象时使用一次回车备用。只有新用户消息包含本次完整文字才确认发送，清空输入框、网址跳转或生成动画不单独视为成功。原生文字输入与上传共用焦点互斥。每个任务分别记录附件接收、文字写入、发送确认，不记录提示词正文；不修改模型、Gem 指令或拒答处理。

## 1.4.22 Gemini 商品图上传修复（2026-10-02）

打包版保留附件真实字节，原生选择器失败后的粘贴、拖入备用上传不再产生空文件；空附件直接报错。原生上传点击阶段跨账号排队，防止抢占焦点，生成回复仍可并行。忽略隐藏的旧上传菜单，超时后取消尚未完成的点击，避免干扰下一个任务。模型、Gem 指令、审核与每日统计不变。新增打包 EXE 的隔离附件粘贴测试，不向 Google 发请求。“待检查”状态在列表、最近任务与详情统一使用橙黄色，与已通过的绿色区分。

## 1.4.21 每日审核通过统计（2026-10-02）

任务列表按 TK 归档账号显示每日通过数量与总计，可选择日期。只统计审核通过且已放行的成片；重复确认和重试不会重复计数。统计与任务列表分开保存，清除任务不会抹掉数量。以通过时本机时区和日期记账，跨天重试沿用首次通过时间。升级可补计仍保有通过时间的旧任务，已删除且无记录的历史无法补计。账号名称按任务归档名称记录，未通过和重做中的任务不计入。

## 1.4.20 审核通过后移动成片（2026-10-02）

成片统一存入 AppData/FlowCut全自动AI视频工作台/review-videos 待检查区（按任务分子目录避免同商品视频重名）。任务列表可直接打开该文件夹。通过后移动到对应账号原定发布目录，不保留待检查视频副本；同盘直接重命名，跨盘先完整写入临时文件、刷盘并删除源视频，再放行 MP4。移动中断可重试，不重复投放。已通过视频的查看链接指向移动后的文件。否决重做仍永久删除旧视频和旧任务。

## 1.4.19 成片审核与重做（2026-10-02）

标准商品任务下载到 AppData 的独立 review-videos 待检查区，不直接进入发布扫描目录。任务显示“待检查”，通过默认外部播放器打开本地成片，不再内嵌播放。二次确认通过后，完整视频直接移动到账号发布文件夹根目录的“商品ID.mp4”；重名则为“商品ID (2).mp4”等，发布程序仍能识别商品。重复审核不重复投放，审核结果持久保存。1.4.23 起启动时将已知旧“已通过/任务ID”下仍存在的已审核视频移到根目录并更新查看链接，仅清理对应空目录，不恢复已发布或已删除的文件。

重新生成默认沿用原任务 Gem 设定快照，也可在任务详情选择其他 Gem；二次确认显示本次所用 Gem。保留图片键快照、商品 ID、时长和地区，从提示词重新开始；旧成片永久删除，旧任务记录删除，列表只留下重做任务。删除失败会提示，可以重试而不重复生成。已通过或正在放行的任务不能直接重做删除。旧任务没有图片快照时只能使用仍保留的商品图片；图片文件已丢失会停止，不拿另一张代替。清除已完成不会清除待检查任务。

账号。工作台会依次完成格式化改写、角色与场景提取、完整分镜拆解、按原顺序组合
分镜，以及 Seedance 2.5 提示词优化。每组未优化分镜合计不超过 25 秒；合计超过
20 秒时最终提示词压缩为一个连续 20 秒视频，20 秒以内则保留原时长。页面会保留
所有中间结果，并为每条最终提示词提供独立复制按钮。生图和生视频暂不在该模块执行。

## 数据边界

- Gem、商品库、商品图片、Gemini/TikTok 登录态、任务和成片保存在每台电脑本机。
- 个人版不连接原来的 FlowCut 云端授权与更新服务。
- 发给别人的安装包不包含制作方电脑的本地 AppData 或网页登录状态。
- Gemini 和 Seedance 生成任务会按功能需要把任务图片和提示词发送到相应第三方平台。

## 开发与验证

要求 Node.js `>=22.13.0`。

```bash
npm install
npm --prefix vendor/publisher install
npm test
npm run lint
cd gemini-web-workbench
npm install
npm run check
npm test
npm run build:win
```

以下为历史商业版说明，个人版已停用这些机制。

从 `1.3.0` 起，正式安装版会通过自有 Cloudflare 控制中心自动检查和下载更新。
安装包、差分 blockmap 和 `latest.yml` 元数据分块保存在 Cloudflare Workers KV，
Workers 更新路由负责版本查询、HTTP Range 下载和断点续传。发布新版本时先构建安装包，再在项目根目录执行
`npm run desktop:update:publish`。免安装版不作为自动更新交付渠道。

授权套餐的并发数按“每台设备”计算，而不是一个账号下所有设备合计。基础版为
1 台设备 × 每台 3 条，专业版为 2 台 × 每台 8 条，团队版为 5 台 × 每台
20 条；旗舰版为 10 台且每台不限并发。定制版的设备数和每台并发数由管理员
在账号编辑窗口单独填写。

桌面程序源码位于 `gemini-web-workbench/`，内置 Seedance 引擎位于
`vendor/seedance-engine/`。项目已经自包含，不再依赖另一份 Seedance 工作台源码。
