# 本机备份与恢复

桌面程序启动五分钟后备份，之后每二十四小时备份。账号与设置页提供立即备份、目录选择和恢复入口。默认目录为“文档\FlowCut备份”，只删除文件名符合 `FlowCut-backup-时间-UUID.zip` 的本程序旧备份，保留七份。目录中其他 ZIP、目录和链接不会删除。

备份通过受桌面令牌保护的本机接口，在一个 D1 batch 事务中导出十四张业务表，收集 R2 媒体、主配置、Seedance 配置/提交日志、发布管理 settings/accounts。不会复制运行中的 SQLite，也不收集 Partitions、浏览器 Cookie 或本机审核视频目录。已下载成片仍须单独保管。

ZIP 使用 Windows 自带 .NET ZIP/ZIP64 实现，无新增 npm 依赖。manifest 记录应用版本、时间、各表行数、媒体键/元数据，以及每个数据文件的字节数和 SHA-256。解压先拒绝越界路径、重复路径、链接和 Partitions；校验清单、哈希与行数之后才开始恢复。

恢复需要两次确认；先暂停 Gemini/Seedance 队列并停止发布管理，等待当前操作结束。覆盖前自动生成一份当前数据备份；表恢复在一个事务中执行。之后替换本机配置并重启。失败后请保留提示中的备份，保持队列暂停，再从该备份恢复。文件系统或磁盘故障不能与数据库跨系统原子提交。

历史备份可能早于平台上的真实提交。恢复合并较新的 Seedance 提交日志，保留不确定时禁止重发的保护；所有历史非成功 Seedance 任务进入 submit_unconfirmed，包括备份时失败、之后可能已重试的任务。该保护在 journal 重放后应用，也覆盖从 journal 补回的任务，并跨后续重启保留，避免网络恢复或旧限流结果将任务再次加入上传队列。网页未完成任务标为失败并提示核对，两个队列保持暂停。核对平台历史后再手动决定是否重新生成；需要重新生成时创建新任务，旧记录保持待核对。表行数、媒体和 Gem 内容保持可核对，任务执行状态会为防重保护而调整。

备份包含本机配置密钥，请保管好目录和 ZIP。恢复保留本机现有 Cookie；另一台电脑需重新登录。Gem 页的“导出全部 Gem”在所选位置新建导出目录，保存完整 JSON 和每个 Gem 的原样指令 TXT，避免浏览器阻止多文件下载。

自动测试使用临时目录、合成图片与假账号，覆盖真实 ZIP 往返、表事务回滚、媒体 SHA-256、篡改拒绝、只保留七份、调度和 Gem 指令不变。真实用户数据未读取或修改。
